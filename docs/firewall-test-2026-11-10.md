# Проверка GFW 0.4 — 10 ноября 2026

## Среда и команды

macOS arm64 для контроллера и браузера. Изолированный Docker `--privileged --network none`, ALT Linux p10 arm64 userspace, nftables 1.1.7, etcnet 0.9.28-alt2, ядро Docker 7.0.14-linuxkit. Сетевые интерфейсы и namespace создавались только внутри одноразового контейнера.

- `make test check`: Go с race detector, vet и проверка синтаксиса трёх JS-модулей — успешно.
- `make test-firewall-linux`: реальная установка/проверка nftables и пакетные тесты — успешно, `ALL ADVANCED FIREWALL TESTS PASSED`.
- `make test-network-linux`: регрессия VLAN/bridge/bond, адресов, маршрутов, etcnet и отката — успешно.
- Контроллер и агент собираются для Linux amd64 и arm64 с CGO_ENABLED=0. Выполнение Linux-тестов проводилось на arm64.

## Пакетные проверки

Базовая регрессия: защита чужой таблицы, IPv4/IPv6 доступ управления с LAN при запретах input/output, блокировка WAN, первый откат, авария SIGKILL и восстановление, восстановление подтверждённых правил после потери состояния ядра, настоящий таймер 30 секунд и позднее подтверждение, корректная остановка.

Новый модуль: типизированные наборы интерфейсов/адресов/портов, схлопывание вложенных CIDR и диапазонов, правила между LAN/WAN, stateful ответы IPv4 и IPv6, блокировка незапрошенного WAN → LAN, masquerade, фиксированный SNAT, приоритетное исключение без SNAT, DNAT WAN → DMZ и запрет прямого доступа к внутреннему серверу, hairpin DNAT/SNAT, запрет перехвата TCP-порта управления на LAN, запрет удаления используемых объектов и повторного назначения интерфейса зоне.

Открытое постоянное HTTP/TCP-соединение LAN → WAN перестало передавать запросы после удаления разрешающего правила. Ручной откат вернул возможность создавать соединения. Откаты SNAT и исключения NAT восстановили предыдущую stateful-политику.

При проверке выявлена особенность текстового вывода nftables 1.1.7: длинное выражение conntrack labels выводится без достаточных скобок и при восстановлении достигает ограничения глубины бинарных операций. Снимок теперь восстанавливает группировку выражения. До изменения правил агент дополнительно выполняет `nft -c` для снимка отката. Успешный повторный пакетный прогон проверил исправление.

## Панель и хранение

Браузерный тест с отдельной временной БД: вход, назначение lan0/wan0 зонам, добавление masquerade, группы адресов и сервиса DNS TCP+UDP, добавление правила с этими группами, сохранение и повторная загрузка. Данные сохранились; ручные поля протокола/порта блокируются при выборе сервиса. Реальная локальная БД не использовалась для тестовых политик.

Автоматические тесты проверяют миграцию старой SQLite-базы без неявного включения stateful, сохранение объектов, сохранение подтверждённой политики в журнале, запрет удаления интерфейса подтверждённой зоны и отсутствие незавершённой транзакции после такого отказа.

## Ограничения проверки

Штатное ядро ALT p10, загрузка узла через systemd и физическое оборудование в этом прогоне не проверялись. Нагрузочное тестирование, полный набор ICMP/related/helpers, IPS, flow offload и NAT66 не проверялись и не объявляются реализованными. Группа TCP+UDP проверялась компиляцией в обе ветви; отдельного UDP-сервера в данном пакетном сценарии нет.

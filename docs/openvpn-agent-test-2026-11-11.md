# Проверка OpenVPN в GFW 0.9

Интеграционный стенд использует ALT Linux p10 aarch64, OpenVPN 2.6.19 и ядро LinuxKit. Два агента работают в изолированных сетевых пространствах. Контроллер доставляет материалы из PKI через Unix-сокет.

- Сервер и клиент устанавливают UDP- и TCP-туннели, передают ICMP и показывают состояние, сеансы и журналы.
- Явные маршруты клиента восстанавливаются после ручного отката, 30-секундного тайм-аута и SIGKILL агента. Дочерний OpenVPN завершается при аварии агента.
- При запрещающей политике nftables доступ через LAN сохраняется. Агент отклоняет пересечение с LAN и захват имени чужого интерфейса.
- Доставка CRL во время ожидающего изменения отключает сеансы. Откат сохраняет номер CRL и запрет повторного подключения.
- Если агент недоступен, API отзыва возвращает статус ожидающей доставки. После перезапуска контроллер и агент синхронизируют CRL.
- В журналах транзакций отсутствует PEM. Постоянный кеш материалов зашифрован.
- Панель сохраняет экземпляры отдельно от существующих профилей экспорта. Регрессионный тест проверяет независимость их ревизий и содержимого.

Команды воспроизведения — `make test check`, `make test-openvpn-linux` и `make test-package-linux`. Пакеты собираются для aarch64 и x86_64. Исполнение проверяется на aarch64 в контейнере.

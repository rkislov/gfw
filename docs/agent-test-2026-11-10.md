# Проверка Linux-агента 10 ноября 2026 года

Проверен код версии 0.2.0-dev. `go test -race ./...` проходит: в том числе конкурирующие сохранения, авторизация/CSRF, идемпотентность применения, тайм-аут, граничное позднее подтверждение, ошибки диска и неопределённый результат вызова nft, повтор отказавшего отката, смена live-правил и восстановление после перезапуска. Дополнительно выполняются `go vet ./...` и `node --check internal/web/assets/app.js`.

Реальная сетевая проверка выполнена в одноразовом контейнере `alt:p10` для aarch64. Установленный пакет: nftables v1.1.7, ядро Docker: 7.0.14-linuxkit. Это userspace ALT p10; загрузка ALT p10 с собственным ядром и systemd в VM или на оборудовании в этой проверке не выполнялась. Статические бинарники собираются для Linux amd64 и arm64.

Стенд запускается с `--network none`, без опубликованных портов и без сети хоста. Внутри контейнера создаются отдельные LAN/WAN namespace и veth-пары. Исходники монтируются только для чтения, журнал находится в отдельном tmpfs. Повторяемые сценарии находятся в `scripts/agent-lab.py`; подготовка и запуск — `scripts/test-alt-p10.sh`.

Полученные результаты:

- Чужая таблица `inet gfw` без метки собственности блокирует запуск; таблица не изменяется.
- `nft -c` принимает сгенерированную политику; реальная атомарная установка работает.
- При пользовательском запрете всего входящего и исходящего трафика TCP-панель на LAN доступна по IPv4 и IPv6. Ответный трафик защищён отдельным системным правилом.
- Через WAN эта панель недоступна по IPv4 и IPv6.
- Повтор одного ID не дублирует правила, конкурирующее применение отклоняется.
- Откат первого применения удаляет только таблицу GFW; посторонняя таблица остаётся.
- После SIGKILL агент при запуске немедленно возвращает предыдущую подтверждённую таблицу; оставшийся Unix-сокет восстанавливается.
- При удалённой из ядра таблице подтверждённая конфигурация восстанавливается при старте.
- Реальный 30-секундный таймер возвращает предыдущую таблицу; позднее подтверждение отклоняется.
- Штатный SIGTERM откатывает неподтверждённое изменение.

Systemd unit-файлы и инструкция подготовлены; запуск unit-файлов в настоящем ALT p10, ранний boot-фильтр, перемена LAN-параметров и интеграция с другими владельцами firewall требуют отдельной системной проверки. Правила и сетевые интерфейсы компьютера разработчика не изменялись.

# Руководство пользователя GFW

## Войти в личный кабинет

1. Откройте HTTPS-адрес GFW, который выдал администратор.
2. Введите имя пользователя и пароль. Используйте пароль GFW, каталога LDAP или RADIUS в зависимости от вашей учётной записи.
3. Если включён второй фактор, введите текущий шестизначный код приложения в отдельном поле.
4. Откройте **Личный кабинет → Мои подключения VPN**. У каждого профиля указаны тип VPN, адрес шлюза и доступные сети, если их указал администратор.

Если профиль отсутствует или недоступен для скачивания, сообщите администратору логин и название нужного подключения.

## Настроить второй фактор

1. В личном кабинете введите текущий пароль и нажмите **Создать ключ 2FA**.
2. Добавьте в приложение аутентификации запись с ручным вводом ключа. Выберите TOTP, 6 цифр и период 30 секунд.
3. Введите код из приложения и нажмите **Подтвердить 2FA** в течение 10 минут. GFW завершит текущий сеанс панели.
4. Дождитесь следующего кода и войдите снова. Для каждого нового входа используйте свежий код. Код, уже принятый для панели или VPN, нельзя использовать повторно.

При смене телефона сначала перенесите запись аутентификатора. При потере доступа попросите администратора сбросить 2FA. Ключ настройки и одноразовые коды следует хранить отдельно от файлов VPN.

## Подключить VPN

### OpenVPN

Скачайте `gfw-openvpn.ovpn` и импортируйте его в клиент, поддерживающий параметры OpenVPN 2.6+. При запросе укажите логин из кабинета. Если профиль требует пароль и второй фактор, в поле пароля введите пароль, двоеточие и текущий код. Например, к своему паролю добавьте `:123456`. Для режима **сертификат + TOTP** введите только шестизначный код. При чисто сертификатном доступе достаточно импортированного файла.

### WireGuard

Скачайте `gfw-wireguard.conf`, импортируйте туннель в приложение WireGuard и включите его. Проверьте доступ к нужной сети. Пароль и 2FA защищают вход в кабинет. Подключение WireGuard выполняется персональным ключом из конфигурации.

### IPsec / IKEv2

Скачайте `gfw-ikev2.zip`. В нём находятся шаблон `swanctl.conf`, сертификат CA, инструкция и, если профиль требует, клиентские ключ и сертификат. Используйте strongSwan с EAP-GTC или совместимый клиент. Для режима с сертификатом и EAP нужны несколько раундов аутентификации. У встроенного VPN-клиента ОС может отсутствовать поддержка этих возможностей.

Для strongSwan скопируйте файлы в соответствующие каталоги swanctl. Укажите пароль, `пароль:код` либо только код по требованиям профиля. Выполните `swanctl --load-all` и `swanctl --initiate --child gfw`. При TOTP для нового сеанса загрузите свежий код. Храните файл с подставленным паролем с доступом только для владельца и замените секрет на шаблон после использования.

## Если подключение не работает

- Проверьте дату и время на устройстве, адрес профиля, доступность Интернета и требования к паролю и коду. Для повторной попытки с TOTP дождитесь следующего кода.
- Если туннель подключился, а ресурс недоступен, передайте администратору время попытки, имя VPN и адрес ресурса.
- Если устройство или файл конфигурации утеряны, сообщите администратору, чтобы он мог отозвать сертификат или отключить ключ. При обращении за помощью передавайте журнал ошибки без паролей, одноразовых кодов и конфигураций с ключами.

На общем компьютере нажмите **Выйти из системы** после работы в кабинете.
